## ✨ Features

| Feature | Description |
|---|---|
| 🎬 **Cinematic Intro** | Anime-inspired "Domain Expansion" overlay with canvas particle effects and phased text reveals |
| 🃏 **3D Profile Card** | Glassmorphic card with mouse-tracked perspective tilt, dynamic glare, and profile/avatar toggle |

| 📥 **Resume Download** | One-click resume download button in the navigation header |
| 🎨 **Custom Cursor** | Animated crosshair target cursor that reacts to hoverable elements |
| 🌌 **Ambient Particles** | Floating particle system with mouse-reactive parallax movement |
| 📱 **Fully Responsive** | Optimized layouts for desktop, tablet, and mobile devices |

## 🚀 Getting Started

### Prerequisites

- **Node.js** ≥ 18
- **npm** or **yarn**

### Installation

```bash
# Clone the repository
git clone https://github.com/roha301/portfolio.git

# Navigate to the project
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```

## 📸 Sections Overview

### 🎬 Intro — Domain Expansion
A cinematic full-screen overlay with animated canvas particles, phased text reveals ("Welcome to my world"), and a dramatic transition into the main content.

### 🏠 Hero
Features a typing role animation cycling through titles, quick stats (Projects, Work Roles, CGPA), and a 3D glassmorphic profile card with mouse-tracked tilt and an avatar toggle mode.

### 👤 About
Personal introduction with animated stat counters, educational background, and interest highlights rendered with intersection observer animations.

### 📊 Skills
Animated progress bars filterable by category (Frontend, Backend, Design, Tools). The tech grid displays official SVG logos for Python, Flask, Flutter, Unity, MongoDB, Kotlin, and more — each clickable and linking to its official website.

### 💼 Projects
A Bento grid layout showcasing key projects:
- **CyberRakshak** — AI-powered cybercrime awareness platform
- **College Hall Reservation System** — Full-stack booking management
- **RecipeVault** — Flutter/Dart/Firebase recipe management app

### 🧑‍💻 Experience
Timeline-based professional experience section with role details and technology badges.

### 🏆 Achievements
A WebGL-powered 3D cylindrical gallery (built with OGL) displaying achievement images with smooth drag/scroll interaction and inertia physics.

### 📬 Contact
Fully functional contact form powered by Web3Forms. Messages are delivered directly to the inbox with sender details, subject line, and message body.

## 🎨 Design Philosophy

- **Dark Futuristic Theme** — Deep backgrounds with purple/blue ambient glows
- **Glassmorphism** — Frosted glass cards with subtle borders and blur effects
- **Micro-Animations** — Smooth intersection observer reveals, hover effects, and floating particles
- **Anime Aesthetic** — Inspired by cyberpunk and anime UI/HUD design elements
- **Typography** — Plus Jakarta Sans for headings, JetBrains Mono for code/labels
